# گام دوم — طراحی: انتخاب منبع داده و بررسی مجوز

**پروژه:** تشخیص سبک موسیقی  
**دامنهٔ این بخش:** فقط تصمیم طراحی دربارهٔ منبع داده و مجوز؛ دانلود، پاک‌سازی، ساخت مجموعهٔ آموزش/آزمون و آموزش مدل در این مرحله انجام نشده است.

## ۱. منبع دادهٔ پیشنهادی

منبع پیشنهادی برای شروع، **Free Music Archive (FMA)، زیرمجموعهٔ `fma_small`** است. مخزن رسمی پژوهش FMA توضیح می‌دهد که این زیرمجموعه شامل ۸٬۰۰۰ قطعهٔ ۳۰ثانیه‌ای در ۸ سبک متوازن است و آن را برای آزمایش تشخیص ژانر معرفی می‌کند. حجم آرشیو صوتی اعلام‌شده حدود ۷٫۲ GiB است؛ بنابراین فضای ذخیره‌سازی و زمان دانلود باید پیش از استفاده در نظر گرفته شود. [۱]

**منبع رسمی و مسیر دسترسی:**

- صفحهٔ پروژه و راهنمای دانلود: https://github.com/mdeff/fma
- فایل صوتی کوچک: https://os.unil.cloud.switch.ch/fma/fma_small.zip
- متادیتا و اطلاعات قطعه‌ها: https://os.unil.cloud.switch.ch/fma/fma_metadata.zip
- مقالهٔ معرفی دیتاست: https://arxiv.org/abs/1612.01840

`fma_small` برای baseline این پروژه مناسب است، چون کوچک‌تر از آرشیوهای کامل FMA است، تعداد سبک‌هایش محدود و متوازن است و برای وظیفهٔ تشخیص ژانر طراحی شده. با این حال، ۷٫۲ GiB هنوز فایل کوچکی نیست؛ اگر فضای اینترنت یا دیسک محدود باشد، ابتدا می‌توان فقط متادیتا را بررسی کرد و سپس نمونهٔ مجاز و کوچک‌تری انتخاب کرد. هنگام دریافت، checksum اعلام‌شده در راهنمای رسمی را نیز بررسی می‌کنم تا از کامل‌بودن آرشیو مطمئن شوم.

## ۲. تصمیم مجوز و استفادهٔ مجاز

**نکتهٔ مهم:** نباید کل فایل‌های صوتی FMA را یکجا دارای یک مجوز واحد فرض کرد. طبق توضیح مخزن رسمی، حق‌نشر صوت‌ها متعلق به صاحب اثر است و هر قطعه تحت مجوزی منتشر شده که هنرمند برای همان قطعه انتخاب کرده است. متادیتای FMA جداگانه با مجوز **CC BY 4.0** منتشر شده است؛ این مجوز متادیتا به‌معنی مجوز یکسان برای فایل‌های صوتی نیست. [۱]

بنابراین برنامهٔ مجوز برای این پروژه چنین است:

1. فایل metadata را دریافت و شناسهٔ هر قطعه را به اطلاعات مجوز/صفحهٔ منبع همان قطعه وصل می‌کنم.
2. پیش از استفاده، برای تک‌تک قطعه‌های منتخب مجوز ثبت‌شده در صفحهٔ منبع را بررسی می‌کنم؛ وجود فایل در FMA به‌تنهایی جای بررسی مجوز را نمی‌گیرد.
3. برای استفادهٔ آموزشی در این پروژه، قطعه‌هایی را انتخاب می‌کنم که مجوزشان استفاده و پردازش موردنظر را صریحاً مجاز می‌کند؛ اولویت با **CC0** یا **CC BY** است. اگر مجوز قطعه روشن، قابل‌ردیابی یا متناسب با استفادهٔ موردنظر نباشد، آن قطعه وارد مجموعه نمی‌شود.
4. اگر قطعه‌ای با مجوز **CC BY** استفاده شود، نام هنرمند، عنوان، لینک منبع و متن/لینک مجوز را در فایل انتساب نگه می‌دارم. اگر مجوز دیگری مثل **CC BY-SA، CC BY-NC یا CC BY-ND** دیده شود، شرایط همان مجوز جداگانه بررسی می‌شود و بدون تأیید تناسب آن با هدف پروژه وارد داده نمی‌شود.
5. فایل‌های صوتی را در مخزن GitHub عمومی بارگذاری یا دوباره توزیع نمی‌کنم. مخزن پروژه شامل کد، مستندات و در صورت نیاز فهرست شناسه‌ها/منابع و مجوزها خواهد بود؛ نه خود فایل‌های صوتی، مگر آنکه مجوز و دستور درس صریحاً اجازه دهند.

این تصمیم، بررسی اولیهٔ آموزشی است و جای مشاورهٔ حقوقی یا تأیید استاد را نمی‌گیرد. اگر استاد استفاده از مجوز خاص، دیتاست داخلی یا منبع دیگری را الزام کرده باشد، همان الزام مقدم است.

## ۳. ثبت منبع و انتساب

برای هر نمونهٔ منتخب، در مرحلهٔ جمع‌آوری یک manifest با ستون‌های زیر نگهداری می‌کنم:

| ستون | مقدار موردنیاز |
|---|---|
| `track_id` | شناسهٔ قطعه در FMA |
| `title` | نام قطعه طبق metadata |
| `artist` | نام هنرمند، در صورت وجود |
| `genre_label` | برچسب سبکی که برای آزمایش انتخاب شده |
| `source_url` | صفحه یا پیوند رسمی همان قطعه |
| `license_name` | نام دقیق مجوز همان قطعه |
| `license_url` | پیوند متن مجوز |
| `checked_on` | تاریخ بررسی صفحه/مجوز |
| `included` | بله/خیر و دلیل انتخاب یا کنارگذاشتن |

برچسب‌های سبک را از taxonomy/metadata دیتاست می‌گیرم و پیش از آموزش، معنی و تعداد نمونه‌های هر کلاس را بررسی می‌کنم. اگر برای پروژه برچسب‌های دیگری لازم باشد، نگاشت برچسب‌ها را مستند می‌کنم و برچسب اصلی را از بین نمی‌برم.

## ۴. محدودیت‌های انتخاب

- اندازهٔ `fma_small` حدود ۷٫۲ GiB است؛ دریافت کامل آن می‌تواند برای اتصال یا دیسک محدود دشوار باشد. [۱]
- ۸ سبک و توزیع متوازن این مجموعه برای آزمایش پایه مناسب است، اما لزوماً نمایندهٔ تمام موسیقی‌ها و فرهنگ‌ها نیست.
- مجوز صوتی باید به‌ازای قطعه بررسی شود؛ مجوز CC BY 4.0 متادیتا را نباید به صوت تعمیم داد. [۱]
- این مرحله فقط انتخاب منبع و طرح مجوز را مستند می‌کند؛ هنوز هیچ داده‌ای دانلود، فیلتر یا ارزیابی نشده است.
